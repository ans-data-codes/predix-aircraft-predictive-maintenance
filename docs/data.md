# Data Strategy

## Intended Data Sources

1. **NASA C-MAPSS** for public aerospace degradation and RUL modelling.
2. **Synthetic aircraft health and maintenance data** for prototype integration and workflow simulation.
3. **Synthetic spare inventory data** for prototype maintenance planning and availability scenarios.

## Data Access Constraint

This prototype must **not** assume access to classified, restricted, or operational defence data. Only public and synthetic datasets are in scope for development and demonstration.
